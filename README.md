# Chemical Plant ML — Process Optimizer

A machine learning web app that predicts and optimizes chemical process outputs using a Random Forest Regressor.

## What it does

**Prediction Mode** — Enter process conditions and get predicted output metrics instantly.

**Optimization Mode** — Enter your target outputs and the model will find the best process inputs to achieve them.

## Inputs & Outputs

| Inputs | Outputs |
|---|---|
| Temperature (°C) | Yield |
| Pressure (bar) | Efficiency |
| Flow Rate (L/hr) | Purity |
| Concentration (mol/L) | |

## Tech Stack

- Python
- scikit-learn (Random Forest Regressor)
- Flask (web framework)
- joblib (model serialization)
- HTML/CSS/JS (frontend)

## Setup

1. Clone the repo
```bash
   git clone https://github.com/aniket-spec/chemical-ml-project.git
   cd chemical-ml-project
```

2. Install dependencies
```bash
   python -m pip install flask scikit-learn joblib numpy
```

3. Train the model (generates model.pkl)
```bash
   python train.py
```

4. Run the app
```bash
   python app.py
```

5. Open your browser at `http://127.0.0.1:5000`
